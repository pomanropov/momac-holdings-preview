static-for-powerpoint/
  Static instances made from the variable fonts for PowerPoint and Keynote,
  which cannot use the width axis:
    Archivo Expanded Light      width 125, weight 300
    Archivo Expanded            width 125, weight 400
    Archivo SemiExpanded        width 112.5, weight 400
    Archivo SemiExpanded Medium width 112.5, weight 500
    Hanken Grotesk              weight 400
    Hanken Grotesk Medium       weight 500
    Hanken Grotesk SemiBold     weight 600
  Archivo line metrics were set to 1.2 (ascent 950, descent 250) so that line
  spacing is the same on Mac and Windows. Install them on any computer that
  opens the PowerPoint files.
